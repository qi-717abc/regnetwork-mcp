## 发布状态与边界

- 本地包构建、安装、stdio、Inspector 及当前 Codex 会话检查通过。GitHub Actions workflow 会在 push/PR 时运行 Windows、macOS、Ubuntu 测试，并构建、检查 wheel 和 sdist；构建作业先按`uv.lock`安装依赖，再关闭 build isolation 使用锁定的 Hatchling。每次 workflow 结果记入行动表。
