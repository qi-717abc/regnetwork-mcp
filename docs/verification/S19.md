# 0.2.1 性能与稳定性验收

日期：2026-10-15（Asia/Shanghai）。工程验收不构成 RegNetwork 生物学内容的专家审查。

## 修改范围

九个工具的名称、参数、输出字段与科研解释保持一致。改进集中在以下实现：

- 上游读取采用有界流式接收，HTTP 解码后的单响应最多32 MiB，mapping最多100000条记录。超过限制明确报错，未完成的响应不会作为完整结果缓存。
- 官方下载和导出使用操作系统文件锁、暂存文件和可恢复提交日志。写入第二个文件失败会回滚；进程中断后，下次合作进程持锁访问时恢复原文件/清单组合。两次重命名不被描述为单个原子操作，恢复保证针对进程中断场景；外部不使用锁的程序仍可能改动文件。
- 下载请求节流和目标文件互斥分开，同一实例最多两个文件传输；保留官网目录白名单、拒绝重定向、8 GiB上限、显式覆盖、不解压和本地SHA-256说明。
- SQLite相关操作与较大解析/导出放到线程执行，取消操作时等待持锁工作真正停止；相关缓存记录批量提交、读缓存按主键直接检查保留期限，复用已有解析对象。
- CI新增最新允许MCP 2.x依赖解析检查，现有锁定依赖与SDK主版本不变。

| 合成负载 | 修改前 | 修改后 |
