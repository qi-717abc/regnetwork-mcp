# S17 官方文件按需下载功能验收

日期：2026-10-14（Asia/Shanghai）。目标版本：0.2.0。此项验证下载工具的工程行为和 MCP 协议，不验证 RegNetwork 数据的生物学意义。

## 官方目录和边界

- 实时读取 [RegNetwork 官方下载页](https://www.zpliulab.cn/RegNetwork/download)，页面返回 HTTP 200。
- 将页面当前列出的 40 个 `.7z` 链接与 MCP 目录逐项比对：human/mouse × core/complete，每组 10 项，链接集合完全一致。
- 新增 `download_official_file`。它只接收物种、集合和官方类别，不接收任意 URL 或本机路径；拒绝重定向；每次仅下载一个文件，单文件上限 8 GiB。
- 下载流写入本机数据目录 `downloads/` 的临时文件，检查 `.7z` 文件头和响应长度，再原子移动到最终文件名。已存在文件默认拒绝覆盖，必须设置 `overwrite=true`。
- 每个压缩包旁保存 `.manifest.json`，记录官方页面、来源 URL、请求条件、时间、大小和本地 SHA-256。官网没有提供独立校验和，因此该 hash 只能用于本机文件一致性核对；MCP 不解压压缩包。
